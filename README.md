# Coursework 2: Aeroplanes API

Курсовой проект на Python для получения, обработки и сохранения информации о самолётах, находящихся в воздушном пространстве выбранной страны.

Проект использует внешние API:

- Nominatim OpenStreetMap для получения географических координат страны;
- OpenSky Network для получения информации о самолётах.

## Возможности проекта

Программа позволяет:

- получить географические координаты выбранной страны;
- получить информацию о самолётах в воздушном пространстве этой страны;
- преобразовать данные OpenSky в объекты Python;
- сохранить информацию о самолётах в JSON-файл;
- получить top N самолётов по высоте полёта;
- отфильтровать самолёты по стране регистрации;
- вывести результаты в человекочитаемом виде через консоль.

## Работа с API

Для работы с внешними сервисами реализован абстрактный класс `BaseAPI`, который наследуется от `ABC`.

Абстрактные методы отмечены декоратором `@abstractmethod`.

Класс `AeroplanesAPI` реализует работу с:

- `nominatim.openstreetmap.org`;
- `opensky-network.org`.

Сначала через Nominatim определяется `boundingbox` выбранной страны.

Полученные координаты используются для запроса информации о самолётах через OpenSky Network.

При работе с API предусмотрена обработка ошибок соединения и некорректных ответов.

## Класс Aeroplane

Класс `Aeroplane` используется для представления информации об одном самолёте.

Основные атрибуты:

- `callsign` — позывной;
- `origin_country` — страна регистрации;
- `velocity` — скорость;
- `altitude` — высота;
- `longitude` — долгота;
- `latitude` — широта.

При создании объекта выполняется валидация текстовых и числовых значений.

Класс поддерживает сравнение объектов самолётов по скорости и высоте.

Также реализованы методы:

- создания объекта из данных OpenSky;
- преобразования набора данных OpenSky в список объектов `Aeroplane`;
- преобразования объекта `Aeroplane` в словарь.

## Работа с файлами

Для работы с хранилищем реализован абстрактный класс `BaseStorage`.

Класс наследуется от `ABC`, а обязательные методы отмечены декоратором `@abstractmethod`.

Класс `JSONSaver` позволяет:

- добавлять информацию о самолёте в JSON-файл;
- получать данные о самолётах;
- получать данные по указанным критериям;
- удалять информацию о самолёте;
- обрабатывать пустой или повреждённый JSON-файл;
- избегать повторного добавления одинаковых данных.

По умолчанию информация сохраняется в:

```text
data/aeroplanes.json
```

## Фильтрация и сортировка

В модуле `src/utils.py` реализованы функции для обработки списка самолётов.

Доступны:

- фильтрация по стране регистрации;
- сортировка самолётов по высоте по убыванию;
- получение top N самолётов по высоте;
- проверка и преобразование введённого пользователем значения top N.

Некорректное значение top N обрабатывается с помощью исключений.

## Консольный интерфейс

Функция `user_interaction()` объединяет компоненты проекта в единую программу.

При запуске пользователь:

1. вводит название страны;
2. получает информацию о самолётах в её воздушном пространстве;
3. вводит количество самолётов для top N;
4. получает top N самолётов по высоте;
5. при необходимости вводит страны регистрации для фильтрации;
6. получает отфильтрованный список;
7. полученные данные сохраняются в JSON-файл.
